# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, argue from evidence, and attack
claims rather than people. Harassment, discrimination, and personal attacks
are not tolerated in any project space (issues, PRs, discussions).

Reports: use GitHub's private reporting on this repository. Maintainers will
review and respond confidentially.
